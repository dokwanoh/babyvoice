# Product Scope

## In scope

- Local-first Korean briefing app for parents and caregivers
- Demo flavor with deterministic mock data
- Lab flavor scaffolding for export files and notification diagnostics
- Lab flavor accessibility widget bridge for the visible BabyTime widget on the user's own tablet
- Lab flavor notification bridge for user-authorized BabyTime notifications from `yducky.application.babytime`
- Production flavor scaffold for a partner API, with a safe "연동 준비 중" path
- Voice input, voice output, deep links, shortcut access, and tablet-first UI

## Out of scope

- BabyTime APK reverse engineering
- Unofficial BabyTime API speculation
- Unauthorized accessibility scraping, certificate bypass, OCR, or MediaProjection collection
- Continuous microphone listening
- Medical recommendations or diagnosis

## First-release promise

The first complete release is the demo flavor. It must work offline, answer in Korean, and clearly show whether the data is fresh or stale.
