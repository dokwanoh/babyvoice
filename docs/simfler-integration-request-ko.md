# Simfler 연동 요청서

프로젝트 목적은 한국어를 사용하는 부모와 양육자가 자신의 육아 기록을 음성으로 빠르게 확인하는 것입니다.

요청 범위:

- 사용자 본인 데이터만 읽기
- read-only 접근
- 최소 필드만 접근
- 로컬 TTS 사용
- 외부 서버에 데이터를 보관하지 않음
- 인증 방식과 권한 회수 방식 문의
- 가능한 연동 방식 문의: API, SDK, ContentProvider, bound service, AppFunctions
- 서면 프로토타입 허가 요청
- 호출량과 rate limit 준수 의사 명시
- 상표 사용 전 별도 승인 필요

이 문서는 공식 허가 요청 초안이며, 실제 승인을 대신하지 않습니다.
